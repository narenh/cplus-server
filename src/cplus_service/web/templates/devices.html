Nicknames

Every client that talks to this service sends its own Plex client identifier, and that identifier is what the Grabs and Activity tables print per row. A name you give one here is used everywhere it appears, so “Living Room” shows up instead of a UUID. Nothing else changes — the identifier itself is still what everything is recorded against.
