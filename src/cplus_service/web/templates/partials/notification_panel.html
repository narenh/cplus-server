Notifications

{# Said on the page rather than in the docs, because it is the whole of what the checkbox commits to and nobody reads the docs before ticking a box. #}

Notifications are delivered in plaintext through {{ relay_host }}, a forwarding service run by the Canopy+ maintainers rather than by you. Apple has to be able to read a notification to display it, so there is no arrangement where the relay forwards without seeing the contents.

Each notification carries a media title and a username. The relay stores none of it and keeps no record of which devices belong to which instance — but it does see it in passing. If that is not acceptable for your instance, leave this off; everything else works without it.
