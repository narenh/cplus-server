2 Prefer, in order

Each row describes a kind of release you would rather have. Every release matching the 1st choice beats every release matching the 2nd, whatever the tie-breakers say. A release matching none of them ranks last — still eligible, just last. This is how "the biggest 4K WEB copy, or failing that the biggest 1080p under 15 GB" gets said.

3 Break ties by

Used inside a choice, when several releases are the same kind. Order matters: the first decides, each later one breaks the ties the previous one left. A choice that takes "the biggest file" has already decided, so these only settle what it could not.
