Drag a row to reorder. Canopy+ draws the first two as buttons on the detail page and folds the rest into a … menu, so the order here is what decides which two a user sees. The built-in action is ranked like any other — put it wherever it belongs.

Icon is an SF Symbol name. The field suggests the ones we know render, and warns on anything else without refusing it: no server can know what symbols a given tvOS version ships, and Canopy+ falls back to arrow.down.circle when it cannot draw the name. Leave it blank for the app's own default.

Name is yours — it identifies the action here, in the grab history and in notifications. Button title is what the Canopy+ app prints on the button; leave it blank and the name is used. Name an action Add to library in HD and title the button Play Now when those are the right words for two different audiences.

The built-in action can be renamed like any other — nothing identifies an action by its name. It cannot be deleted (the next start would seed it again) and it takes no download client or quality profile, because it files a request in Seerr rather than grabbing anything. Request is the one word held back for it: on any other button it would promise a user the one thing that button cannot do.
